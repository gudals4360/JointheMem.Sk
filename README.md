# Shin_DutyFree — 신세계면세점 회원가입 UX 개선

신세계포인트 × 신세계면세점 통합회원 가입 과정을 더 쉽게 만들기 위한 **모바일 UX 프로토타입**입니다.
`index.html` 한 파일로 동작하며, 실제 인증·가입은 진행되지 않습니다.

## Before / After: 8단계 → 5단계 (3단계 감소)

| STEP | Before (현재 회원가입) | After (개선 회원가입) | 변화 |
| --- | --- | --- | --- |
| 1 | 가입 방식 선택 | 가입 방식 선택 + **설명** | 개선 |
| 2 | 본인 인증 | 본인 인증 + **진행 안내** | 개선 |
| 3 | 회원정보 입력 | **필수 정보 입력** + **오류 예방** | 개선 |
| 4 | 주소 검색 | 필요할 때 추가 입력 | 선택으로 분리 |
| 5 | 약관·마케팅 동의 | **필수·선택 약관 구분** | 개선 |
| 6 | 동의 처리 팝업 | 제거 | 삭제 |
| 7 | 통합회원 계열사 안내 | 제거 | 삭제 |
| 8 | 면세점 가입 완료 | 가입 완료 + **쇼핑 연결** | 개선 |

- **필요할 때 추가 입력**: 주소, 마케팅 수신 채널 등은 필요성과 동의 여부에 따라 별도로 제공합니다.
- 단계 수는 8 → 5로 줄었지만, 줄어든 단계의 내용이 사라진 것은 아닙니다.
  - 동의 처리 팝업 2개는 가입 완료 화면의 동의 현황 목록으로 합쳤습니다.
  - 계열사 안내(통합 ID 서비스)는 약관 동의 화면 안의 체크박스 목록으로 옮겼습니다.
  - 주소는 정보 입력 화면의 선택 항목(비워도 다음으로 이동)으로 분리했습니다.

## 실행

빌드 없이 `index.html`을 브라우저에서 열면 됩니다. 데스크톱에서도 휴대폰 폭의 프레임으로 보입니다.

- 글꼴(Pretendard)과 주소 검색(다음 우편번호)은 인터넷에서 불러옵니다. 오프라인에서는 기본 글꼴로 보이고 주소 검색은 동작하지 않습니다.

## 가입 흐름 (4단계)

| 단계 | 화면 | 내용 |
| --- | --- | --- |
| 1/4 | 가입 방식 선택 | 통합회원 가입, 외국인 가입, 카카오·앱카드 간편가입 선택. 가입 혜택 캐러셀 안내 |
| 2/4 | 본인 인증 | 휴대폰 · 신한인증서 · 카드 인증 중 선택 (시연용으로 실제 인증 없이 이동) |
| 3/4 | 정보 입력 | 아이디(중복확인), 비밀번호 규칙 체크, 이름·휴대폰(인증값), 이메일, 자택주소(선택) |
| 4/4 | 약관 동의 → 가입 완료 | 아래 "약관 동의 개선" 참고 |

화면 상단의 진행 표시는 위 5단계 중 "필수 정보 입력"까지를 1~3, 약관 동의와 완료를 4로 묶어 `n/4`로 보여 줍니다. 각 단계의 추가 요소(1단계 설명, 2단계 진행 안내, 3단계 오류 예방, 5단계 쇼핑 연결)는 화면에 이렇게 들어 있습니다.

- 가입 방식 선택: 혜택 캐러셀과 방식별 캡션으로 선택 이유를 설명
- 본인 인증: 선택한 방법을 버튼 문구에 반영하고 이동 중 토스트로 진행 상황 안내
- 정보 입력: 아이디 중복확인, 비밀번호 규칙 실시간 체크, 이메일 자동 분리 등으로 입력 오류를 미리 방지
- 가입 완료: "쇼핑 시작하기" 버튼으로 쇼핑에 바로 연결

가입 방식 선택에서는 **신세계포인트 통합회원 가입**만 다음 화면으로 이동하고, 나머지는 "프로토타입에서 준비 중" 안내가 뜹니다.

## 개선 포인트

등록된 이슈(#1~#7)를 기준으로 기존 가입 화면의 불편했던 점을 이렇게 바꿨습니다.

### 정보 입력

- **비밀번호 확인은 확실히 틀렸을 때만 오류** ([#1](../../issues/1))
  확인칸 값이 원래 비밀번호의 앞부분이면 아직 입력 중으로 보고 안내하지 않습니다. 확인칸을 벗어났는데 다르거나 길이를 넘겼을 때만 "일치하지 않아요"가 뜹니다.
- **우편번호 직접 입력 지원** ([#2](../../issues/2))
  숫자 5자리를 입력하면 바로 주소 검색 결과가 열립니다. Enter 키와 "주소 검색" 버튼으로도 검색할 수 있고, 숫자는 5자리를 넘지 않게 막습니다.
- **필수 정보 위주로 입력** ([#5](../../issues/5), 일부 반영)
  자택주소는 선택 항목이라 비워도 다음으로 넘어갑니다. 다만 주소 입력창이 아직 같은 화면에 있어서, 가입 후 별도 단계로 옮기는 작업이 남아 있습니다.

### 약관 동의

1. **필수와 선택을 한눈에 구분** ([#4](../../issues/4), [#3](../../issues/3))
   - 필수: 파란 테두리 + 왼쪽 굵은 파란 바 + 파란 `필수` 배지. 동의하면 행 전체가 연한 파랑으로 바뀝니다.
   - 선택: 회색 배경 + 얇은 테두리 + 회색 `선택` 배지.
   - 필수를 모두 동의하기 전에는 하단 버튼이 "필수 동의 N개 남았어요"로 비활성화됩니다.
   - 체크 부담은 **전체 동의하기** 하나로 줄였습니다. 선택 체크박스(서비스 9개, 마케팅 8칸)는 아직 많아서 접어 두거나 줄이는 방안은 결정이 필요합니다.
2. **마케팅 수신 동의는 한 곳에서, 결과는 한 번만** ([#6](../../issues/6))
   - 신세계포인트와 신세계면세점을 하나의 표로 합쳤습니다. 행은 이메일·문자·우편·전화, 열은 신세계포인트·신세계면세점이며 야간(21~08시) 수신은 면세점 한정입니다.
   - 표 아래 요약에서 채널별 `동의` / `미동의`가 바로 보입니다.
   - 기존의 결과 팝업 2개는 없애고, 가입 완료 화면의 **동의 현황 목록** 한 곳으로 합쳤습니다.
3. **통합 ID 서비스 한 번에 동의** ([#7](../../issues/7))
   - 맨 위 **전체 동의하기**로 필수 + 선택 항목을 한 번에 동의할 수 있습니다.
   - 서비스 9개(이마트, 신세계백화점, 신백멤버스, 신세계아울렛, 시코르, 이마트에브리데이, 신세계까사, 스타필드, 이마트24)는 "9개 서비스 한 번에 이용" 체크박스 하나로 묶었고, 서비스별 체크박스는 기존의 브랜드 색 바 UI를 유지하면서 높이를 줄였습니다.
4. **가입 완료 화면에서 확인·수정**
   - 필수 약관, 통합 ID 서비스 이용 수, 마케팅 채널별 동의/미동의, 변경일을 한 카드에서 보여 주고 "동의 내용 수정"으로 돌아갈 수 있습니다.

## 디자인

[`gs-shop.md`](gs-shop.md)의 디자인 토큰을 기준으로 했습니다.

- 계정·인증 동선은 파랑(`#0F78FF`), 글꼴은 Pretendard
- 4px 배수 간격, 라운드 8 / 12 / 16px, 하단 고정 48px 버튼
- GS SHOP의 로고·클래스명 등 브랜드 식별자는 가져오지 않고 시각 언어만 참고했습니다.

## 구조

```
.
├── index.html   # 전체 프로토타입 (화면 5개, CSS·JS 포함)
├── gs-shop.md   # 디자인 토큰 명세
└── README.md
```

화면은 `entry → verification → info → consent → done` 순서로 `history` 기반으로 전환되며, 각 화면의 뒤로가기는 `history.back()`입니다.

## 다른 화면·서버와 연결하기

정보 입력 화면은 외부와 이어 붙일 수 있게 열어 두었습니다.

- `ShinInfo.config.checkIdAvailable(id)`: 아이디 중복확인. 지금은 시연용 목록으로 판단하며, 서버가 생기면 이 함수만 `fetch`로 바꾸면 됩니다.
- `ShinInfo.setVerified({ name, phone })`: 본인인증 결과를 넘겨 이름·휴대폰을 채웁니다. 값이 없으면 예시 값을 보여 줍니다.
- 입력 완료 시 `shin:info-complete` 이벤트(`detail`에 입력값)와, iframe 안이면 `postMessage`로 같은 내용을 보냅니다. 비밀번호는 `sessionStorage`에 저장하지 않습니다.

## 알려진 한계

- 필수 약관 3건(이용약관, 개인정보 수집·이용, 만 14세 이상)의 문구와 "보기" 약관 전문은 임의 값입니다. 실제 문구로 교체가 필요합니다.
- 서비스 브랜드 색과 로고 자리 텍스트는 기존 화면 캡처에서 눈대중으로 옮긴 값입니다.
- 동의 결과는 서버에 저장되지 않고 화면에서만 확인할 수 있습니다.
